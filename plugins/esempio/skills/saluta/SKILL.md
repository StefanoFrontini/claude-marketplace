# Saluta

1. Saluta l'utente in italiano, in modo breve e cordiale.
2. Ricava il nome della cartella corrente e, se è un repo git, il branch attivo (`git branch --show-current`).
3. Rispondi con una sola riga, ad esempio: `Ciao! Sei in <cartella> sul branch <branch>.`
